# accordion-faq

Custom **accordion** block. Purpose: faq.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per item: cell 1 = question (plain text; a heading or paragraph wrapper is unwrapped because headings are not allowed in summary); cell 2 = answer paragraph(s) with inline links. Rendered as native details/summary elements..
