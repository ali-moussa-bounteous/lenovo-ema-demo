# anchor-nav-sticky

Custom **anchor-nav** block. Purpose: in-page-jump-nav.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 column, one row per jump link (link text -> #id of the target section heading). Optional plain-text cell = accessible nav label (default "On this page"). Links whose target id is not on the page are dropped (e.g. Reviews while that section is excluded). Author the block in its own section: the section is what sticks..

## Supported variations

No variations.
