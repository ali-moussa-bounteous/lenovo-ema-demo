# cards-listing

Custom **cards** block. Purpose: product-listing.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile: cell 1 = product image; cell 2 = optional badge paragraph, product-name heading (link to PDP), optional short sub-label, "Starting at" + price paragraph, spec bullet list, link (button). Badge/heading/sub-label render above the image. A row without a heading (merchandising promo) keeps authored order..

No variations.
