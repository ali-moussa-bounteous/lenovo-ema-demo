# cards-product

Custom **cards** block. Purpose: product-recommendations.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 2 columns, one row per product. Cell 1 = product image; Cell 2 = paragraph with the linked product name, then a price paragraph (e.g. bold $2,095.99). The name link makes the whole tile clickable; prices are static authored text.

## Supported variations

No variations.
