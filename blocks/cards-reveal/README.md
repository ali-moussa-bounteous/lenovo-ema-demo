# cards-reveal

Custom **cards** block. Purpose: feature-reveal-tiles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: collection-like standalone: one row per tile. Cell 1 = tall photo; cell 2 = icon image, heading (level kept as authored), description paragraph(s). Images are taken in order (first = photo, second = icon). The heading becomes a disclosure button; the description is revealed on hover, focus, or tap..

No variations.
