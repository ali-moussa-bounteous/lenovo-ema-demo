# cards-tile

Custom **cards** block. Purpose: image-tile-links.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile, 2 cells: cell 1 = image, cell 2 = H3 title + description paragraph + link (the link becomes the whole-tile link); more than 3 rows render as a horizontal scroller.
