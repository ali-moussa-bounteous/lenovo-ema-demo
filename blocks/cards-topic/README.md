# cards-topic

Custom **cards** block. Purpose: topic-category-list.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 2 columns, one row per topic. Cell 1 = landscape photo; Cell 2 = H3 heading containing the topic link, description paragraph, and a final link-only paragraph (e.g. 'Explore All Articles', may be bold). Items stack image-on-top on mobile and image-left (~45%) / text-right from 600px.
