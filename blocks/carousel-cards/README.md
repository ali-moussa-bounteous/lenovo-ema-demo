# carousel-cards

Custom **carousel** block. Purpose: benefit-card-carousel.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 2 columns. Optional first row = a single image cell with no text (band background, decorative). Then one row per slide: Cell 1 = slide background art image followed by the character image (two images, background first); Cell 2 = H3 headline, description paragraph, and a final link-only paragraph (e.g. 'Learn More') rendered as a button. Slides scroll horizontally with snap; from 900px three cards show with the centered (active) card enlarged; prev/next buttons and arrow keys move between slides; no autoplay.
