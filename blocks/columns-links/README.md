# columns-links

Custom **columns** block. Purpose: link-list-panels.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 row x 2 cells (one cell per panel). Each cell = H2 heading (e.g. 'Shop' / 'Explore'), bulleted list of links, and an optional decorative image (last, anchored bottom-right). Panels sit side-by-side from 900px and stack below; extra cells or rows become additional panels.

## Supported variations

No variations.
