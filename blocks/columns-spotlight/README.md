# columns-spotlight

Custom **columns** block. Purpose: product-spotlight.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 row, 2 cells. Cell 1 (product panel) = heading, product image, price text, link (button). Cell 2 (photo panel) = background photo first, then heading, text, link (button) and optional logo image. Any cell that starts with an image and also has text renders as a photo panel. 2 cells render ~30/70 from 900px..

No variations.
