# embed-video

Custom **embed** block. Purpose: feature-video.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 column. Poster image and a YouTube (or Vimeo) link, in one or two rows. Optional plain-text line (or non-URL link text) is used as the player title. The iframe is created only when the play button is pressed..

No variations.
