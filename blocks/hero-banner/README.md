# hero-banner

Custom **hero** block. Purpose: page-intro-banner.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 column, 2 rows. Row 1 (cell 1) = banner image; Row 2 (cell 1) = H1 heading + intro paragraph(s). Image may also share the text cell; the image loads eagerly as the first visible image of the page.
