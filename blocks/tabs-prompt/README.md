# tabs-prompt

Custom **tabs** block. Purpose: guided-prompt-selector.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional single-cell intro row (heading and/or panel background image); then one row per prompt, 2 cells: cell 1 = prompt label, cell 2 = result items authored sequentially as image, H3 title, paragraph, link (each image starts a new result).

No variations.
